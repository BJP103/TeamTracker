# TeamTracker

### Problem Statement
This app is to keep track of your favorite NFL without searching or googling yourself.

### Target User
This app is for sport fans who wish to have an easy way to keep track of their favorite team.



### Core Features
- GUI
- Searchbox to search team
- Notifications to update user
- Save team for user

### User Interaction Flow
- User opens app
- User click on search box and types their favorite team
- The user will see information on their team like roaster and record or draft order

### Components
- App
- Header
- Searchbox
- ItemList

### State and Data
The data that will be is searched data for teams and information for teams

### Instructions

run npm run start

select your team and look at the roster and news

### Screen List
Home screen
    - Blank blue screen with logo and color palette

Team Select
    - A screen to select one of the 32 teams as your team

Roster View
    - A screen to view your teams updated roster

News View
    - A screen to see the lastest news about your team
